One library, three kinds of user

Choose the correct user type before you login. The system shows different options to each type of user.

Which user type do I choose?

  • Student – search and read the books of your organization.
  • Librarian – add, edit and organise the book collection.
  • Administrator – manage user accounts and view reports.

Trouble signing in?

  • Check that Caps Lock is off before typing your password.
  • Use the User ID given by your organization, not a personal email.
  • Still stuck? Contact the librarian of your institution.
