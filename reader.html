4.1 Introduction

Python is a high-level programming language designed to emphasize readability and simplicity. Functions allow a program to divide a large task into smaller reusable blocks.

4.2 Functions

A function is a named block of code that performs a specific task. It can receive input through parameters and may return a result.

Example:

def add(a, b):
    return a + b
